# Time Is Running ❤️

## No photo renaming needed

Put any number of image files inside `photos/`.

Examples:

- `IMG_3821.jpg`
- `WhatsApp Image 2026-09-20 at 10.15.02.jpeg`
- `DSC0045.png`
- `memory.webp`

The website automatically discovers them from GitHub. **Do not rename them.**

## Important

The photo discovery works after deployment on **GitHub Pages**. If you double-click `index.html` on your computer, the browser cannot list the `photos` folder, so it will show a message instead. That is normal.

## GitHub Pages

1. Create a **Public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `photos` folder.
3. Put all your photos inside `photos`.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`.
7. Save and open the GitHub Pages URL.

The countdown ends on **15 October 2026 at 11:59:59 PM IST**.
